# DesignYourTaol — Interactive 3D Coffin Customizer

A web-based 3D coffin customization system that transforms the traditional manual customization process into a digital, interactive, and visual experience.

🌐 **Live Site:** https://designyourtaol.netlify.app/

## Features
- 3D real-time coffin preview
- Multiple starting models to choose from
- Full customization (color, material, finish)
- Interactive design studio
- Responsive design
